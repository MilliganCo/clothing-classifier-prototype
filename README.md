# Clothing Classifier Prototype

## Описание

Прототип пайплайна для классификации одежды по изображениям. В проекте есть подготовка датасета, переименование файлов, валидационные проверки и обучение модели на базе `MobileNetV2`.

## Что внутри

- `change_format.py` для приведения изображений к единому размеру и формату
- `rename_files.py` для нормализации структуры датасета
- `model_learn.py` с обучением классификатора на `TensorFlow / Keras`
- вспомогательные скрипты проверки и валидации

## Стек

- Python
- TensorFlow / Keras
- Pillow
- Matplotlib

## Статус

WIP. Это экспериментальный ML-проект, где основной интерес представляет код подготовки данных и обучения, а не готовый production-пайплайн.

## Как использовать

1. Подготовить структуру изображений по классам.
2. При необходимости прогнать нормализацию и переименование файлов.
3. Запустить обучение:

```bash
python model_learn.py
```

## Примечание

В репозиторий не включаются датасеты, обученные веса, тестовые изображения и другие тяжёлые артефакты.
